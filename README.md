# Profile Card UI/UX Design

A simple and modern **Profile Card UI** created using **HTML and CSS**.
The design contains a profile section, social media icons, action buttons, and engagement statistics.

## 📌 Project Preview

This project is designed as a profile card with:

* Profile image
* Developer information
* Social media icons
* Subscribe and Message buttons
* Likes, comments, and shares statistics
* Modern shadows and rounded corners
* Navy blue and white color theme

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Font Awesome 6.5.2**

## 🚀 How to Run

1. Download or clone the project.
2. Keep `index.html` and `2.PNG` in the same folder.
3. Open `index.html` in any modern web browser.
4. The Profile Card UI will appear on the screen.

## 🔗 Font Awesome

This project uses Font Awesome for social media and statistics icons.
